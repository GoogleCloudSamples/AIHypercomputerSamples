# RL Tuning on Llama 3.1 8B Model

This code sample demonstrates how to run Reinforcement Learning post-training on Llama 3.1 8B model using MaxText on a single TPU v6e-8 machine.

You can find the full documentation article about this on [official Google Cloud documentation page](https://docs.cloud.google.com/ai-hypercomputer/docs/tutorials).
