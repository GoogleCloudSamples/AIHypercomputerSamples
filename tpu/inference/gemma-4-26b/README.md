# Gemma 4 26B multi-host inference on TPU v6e

This code sample demonstrates serving `google/gemma-4-26B-A4B-it` with vLLM on a
multi-host TPU v6e (2x4) slice in GKE, using LeaderWorkerSet and Ray.

You can find the full documentation article about this on [official Google Cloud documentation page](https://docs.cloud.google.com/ai-hypercomputer/docs/tutorials/).
