# Use FSDP to fine-tune Mixtral-8x7B on an A4 Slurm cluster

This repository contains code samples and scripts from the AI Hypercomputer documentation.

## Tutorial

For a step-by-step guide on how to use these files, please refer to the official tutorial:
*   **[Use FSDP to fine-tune Mixtral-8x7B on an A4 Slurm cluster](https://docs.cloud.google.com/ai-hypercomputer/docs/tutorials/gpu/fsdp-mixtral-8x7b)**

## Overview

This sample demonstrates how to fine-tune Mixtral-8x7B on a Slurm cluster with NVIDIA B200 GPUs. It uses PyTorch FSDP to set up a distributed training environment to fine-tune the model.
