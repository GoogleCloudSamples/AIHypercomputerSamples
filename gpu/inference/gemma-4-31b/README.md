## Overview

This sample demonstrates how to serve the Gemma 4 31B large language model (LLM) with vLLM on a Google Kubernetes Engine (GKE) Autopilot cluster that uses an A4 virtual machine (VM) instance. It deploys the vLLM inference server on one A4 node with 8 NVIDIA B200 GPUs and sends a chat completion request to the model through its OpenAI-compatible API.
