# Serve Qwen3 235B on GKE using vLLM

This code sample demonstrates how to run inference with the Qwen3 235B model serving with vLLM on GKE Autopilot using NVIDIA B200 GPUs.

You can find the full documentation article about this on [official Google Cloud documentation page](https://docs.cloud.google.com/ai-hypercomputer/docs/tutorials).
