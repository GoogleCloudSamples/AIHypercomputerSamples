# Serve DeepSeek-V3.2-Speciale on GKE using vLLM

This code sample demonstrates how to run inference with the DeepSeek-V3.2-Speciale model serving with vLLM on GKE Autopilot using NVIDIA B200 GPUs.

You can find the full documentation article about this on [official Google Cloud documentation page](https://docs.cloud.google.com/ai-hypercomputer/docs/tutorials).
